# 第一版产品范围

## 1. 产品定义

第一版 PDF Toolbox 是一个 Windows 本地 PDF 预览器。它的任务不是替代 Acrobat，而是证明我们能够安全、稳定地处理真实 PDF，并为后续页面整理、合并拆分、标注和 OCR 建立可信基础。

## 2. 目标用户

主要用户是需要阅读大量论文、扫描资料和技术文档的学生及科研工作者。

第一版关注的核心体验：

- 不注册账号即可使用；
- 文件完全留在本机；
- 打开文档后能尽快看到第一页；
- 大文档不会因为一次性渲染全部页面而卡死；
- 遇到损坏、加密或不支持的文件时给出明确提示；
- 关闭应用后，原 PDF 的内容和时间戳不应发生变化。

## 3. 第一版必须实现

### 文件操作

- 从系统文件选择器打开一个 PDF；
- 支持中文、空格、括号及常见 Unicode 文件名；
- 支持拖放打开一个 PDF；
- 关闭当前文档；
- 显示文件名、文件大小和页数；
- 默认以只读方式访问输入文件。

### 阅读

- 渲染当前页面；
- 连续滚动或单页模式至少实现一种，首选连续滚动；
- 上一页、下一页和页码跳转；
- 放大、缩小、适合宽度、适合页面；
- 显示当前页和总页数；
- 基础页面缩略图；
- 页面渲染失败时不使整个应用退出。

### 状态和错误

- 打开和解析期间显示忙碌状态；
- 区分不存在、无权限、加密、损坏、不支持和未知错误；
- 能取消耗时较长的加载或渲染任务；
- 日志中不得记录 PDF 正文或用户敏感路径之外的不必要信息。

## 4. 第一版明确不实现

- 修改或覆盖原 PDF；
- 保存 PDF；
- 合并、拆分、删除、旋转或重排页面；
- 高亮、批注及书签编辑；
- OCR；
- PDF 与其他格式互转；
- 表单填写和数字签名；
- 云同步、账号和遥测；
- 自动更新；
- macOS、Linux 和移动端发行。

这些能力属于后续阶段，不代表永久排除。

## 5. 首版验收标准

第一版只有同时满足以下条件才算完成：

1. 能打开测试集中所有被标记为“应支持”的 PDF；
2. 加密、损坏或不支持的文件产生可理解的结果，而不是崩溃；
3. 打开、浏览和关闭文件后，原文件字节、大小和修改时间保持不变；
4. 500 页文档不会在启动时渲染全部页面；
5. 快速滚动时，离开视口的渲染任务可以取消或降级；
6. 连续开关不同文件不会持续增长内存；
7. 普通错误不会留下临时文件或后台进程；
8. 在至少 Edge、Firefox 或 Acrobat 中确认测试文件打开正常，以排除样本自身问题。

## 6. 暂定界面

第一版采用简化两栏布局：

```text
┌───────────────────────────────────────────────┐
│ 打开   上一页 下一页   页码   - 100% +   适宽 │
├───────────┬───────────────────────────────────┤
│ 页面缩略图 │                                   │
│           │             当前页面              │
│           │                                   │
├───────────┴───────────────────────────────────┤
│ 就绪 / 正在加载 / 错误                         │
└───────────────────────────────────────────────┘
```

右侧属性或操作面板等到页面编辑功能出现时再加入。
