# P1 最小桌面窗口验证

状态：通过（P1 第一部分）
日期：2026-09-23

## 验证目标

确认 Windows 上的最小技术链路能够工作：

```text
Tauri 2 窗口
  → WebView2
  → React/TypeScript
  → 用户明确选择本地 PDF
  → PDF.js Worker
  → Canvas 渲染第一页
```

本次不验证正式界面、连续阅读、页面缓存、保存或编辑能力。

## 实现边界

- 通过原生文件输入框选择单个 PDF；
- 文件字节仅交给 PDF.js；
- 只渲染第一页；
- 不向 Rust 后端暴露文件路径；
- 没有保存、覆盖或修改命令；
- 没有外部链接插件；
- Tauri 权限仅保留 `core:default`；
- 禁用 XFA，未创建脚本管理器或批注层；
- 使用 CSP 禁止内联脚本和动态脚本执行；
- PDF.js 固定为已修复已知高危漏洞的 6.3.289。

## 构建结果

- TypeScript 类型检查：通过；
- Vite 生产构建：通过；
- Cargo/Tauri 编译检查：通过；
- Tauri 开发版启动：通过；
- npm 高危安全审计：0 个已知漏洞；
