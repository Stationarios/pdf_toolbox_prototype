# 第一版仅实现安全的只读预览

状态：接受
日期：2026-09-23

## 背景

项目长期希望支持合并、拆分、标注、导出标注、区域文字选择和 OCR。但上述功能同时开展会混合渲染、交互、PDF 写入、外部工具和文件安全等多类风险。

## 决定

第一版只实现 Windows 本地 PDF 预览，不提供任何写入能力。只有只读预览经过真实文件和安全测试后，才开始页面编辑和文件输出。

## 原因

- 建立可信的打开、渲染、取消和资源释放基础；
- 第一版无法通过代码路径修改原文件；
- 尽早验证 PDF.js、Tauri 和 WebView2 的组合；
- 降低第一次桌面应用开发的学习面。

## 后果

- 第一版暂时不能解决最迫切的合并拆分需求；
- 开发顺序更慢，但后续写入建立在已验证的文档模型上；
- 测试能够首先聚焦“能打开、不会改、不会崩”。

## 备选方案

直接从 qpdf 合并拆分界面开始。该方案能更早提供实用功能，但无法同时建立阅读器架构，并会过早引入写文件风险。
