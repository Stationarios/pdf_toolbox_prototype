# Security Policy

English | [简体中文](SECURITY.zh-CN.md)

PDF is a complex input format that can be crafted maliciously. This project is currently an early prototype and must not be treated as a security-hardened PDF sandbox.

## Supported versions

Until the first formal release, only the latest code on the default branch is maintained. Older commits do not receive security updates.

## Reporting a vulnerability

Do not open a public issue for an undisclosed vulnerability. Once GitHub Private Vulnerability Reporting is enabled, use **Security → Report a vulnerability** in the repository. If that option is not available yet, wait for the maintainers to publish a private contact method; do not attach a real or sensitive PDF.

Please include the affected commit or version, minimal reproduction steps, and the likely impact. Provide only a sanitized fixture that you are legally allowed to share, or instructions for generating one.

Never send real research papers, textbooks, personal documents, passwords, or other sensitive material. Public disclosure should be coordinated after the maintainers have confirmed the issue and prepared a fix.
